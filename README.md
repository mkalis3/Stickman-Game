# Stickman Game

Embedded C arcade game for a PIC32-based board with LCD output, keypad input, timer-driven sound, and a simple real-time game loop.

## Features

- 16x2 LCD rendering
- Matrix keypad scanning
- Timer-based square-wave sound effects
- Menu, win, and lose melody states
- Switch-controlled restart, difficulty, and menu actions
- Interrupt-driven audio timing

## Hardware Assumptions

- PIC32 target using XC32
- LCD data lines on port E
- LCD control lines on RB15, RD5, and RD4
- Keypad rows on RC2, RC1, RC4, and RG6
- Keypad columns on RC3, RG7, RG8, and RG9
- Board switches on RF3, RF5, RF4, and RD15

## Build

The repository contains the MPLAB/NetBeans project files generated by the IDE.

```bash
make build
```

For a clean rebuild:

```bash
make clean
make build
```

## Source Layout

```text
main.c
Makefile
nbproject/
```

The current implementation keeps the board setup, LCD driver, keypad scanner, sound, and game loop in `main.c`. A good next cleanup is splitting those sections into dedicated modules.
